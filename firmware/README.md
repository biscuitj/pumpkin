# Pumpkin firmware

Firmware for the Ulanzi TC001 pixel clock (ESP32, 32×8 LEDs). It shows the
glucose, trend, time in range, active insulin and pump alerts from the Pumpkin
bridge (`../bridge`), with a display pet in between. It is set up and
configured from its own dashboard (`dashboard/`), served by the clock.

Pumpkin 1.0 is a rewrite. It started from [SugarClock](https://github.com/cdemeke/SugarClock)
0.2.15 by Chris Demeke (MIT licensed, see `LICENSE`) and keeps its ideas
(Wi-Fi setup hotspot, first-boot rollback, the pets' pixel art), but reads only
the Pumpkin bridge: no Dexcom, LibreLinkUp, Nightscout, weather, timers or
buzzer alerts.

Installing, updating and recovery: [`INSTALL.md`](INSTALL.md).

## Layout

- `src/core/`: everything that decides what the clock does, as plain C++ with
  no Arduino calls: settings and validation, the `/clock` parser, the display
  engine (screens, rotation, fades, brightness, pets), schedule, the HTTP API
  (`api.cpp`, the contract in `dashboard/src/contract.ts`), the bridge fetches
  (`net_jobs.cpp`) and the upload check. `platform.h` is what it needs from
  the hardware.
- `src/hal/`: the ESP32 side: LEDs, buttons and light sensor, time (DS1307,
  NTP, the bridge's `Date` header), NVS storage, Wi-Fi and the setup hotspot,
  the network task (HTTPS with pinned roots, reachability checks, mDNS), the
  web server and updates.
- `src/main.cpp`: start-up and the main loop.
- `host/`: the core built for your computer: unit tests and a simulator that
  serves the real API and rendering on `localhost:8080`.
- `dashboard/`: the web UI (Preact). `pio run` builds it and embeds it.

## Development

```bash
pip install -r requirements-build.txt      # PlatformIO, pinned
pio run                                     # build (also builds the dashboard; needs Node.js 20+)
pio run -t upload                           # flash over USB (the USB guard checks the device first)
make -C host test                           # unit tests of the core (needs a C++17 compiler)
python3 -m unittest tests.test_upload_guard # USB guard tests
python3 scripts/check_layout.py             # partitions, version, rollback hook (after pio run)
```

Dashboard work without a clock: `make -C host sim && host/sim`, then in
`dashboard/`: `PUMPKIN_HOST=localhost:8080 npm run dev`. The simulator fakes
Wi-Fi and the bridge (see the top of `host/sim.cpp` for inputs that trigger
failures).

The version comes from `VERSION` (strict `major.minor.patch`) and is injected as
`PUMPKIN_VERSION` at build time. `src/hal/tls_roots.h` is generated by
`scripts/make_roots.py` from the Mozilla CA bundle.
